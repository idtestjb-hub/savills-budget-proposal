- [ ] 3.2 Reject an invalid horizon — zero or fractional years, negative or fractional pre-opening

      Excel COM with zero cells resolving to a spreadsheet error; negative — an injected unclassifiable
      reference stops generation and names the cell.
- [ ] 3.5 Add the per-code escalation flag to `Costing_Method_Catalogue.csv` (design D5), defaulting to

- [ ] 3.8 Extend the summary to a column group per phase, appended to the right of year 1's group.
