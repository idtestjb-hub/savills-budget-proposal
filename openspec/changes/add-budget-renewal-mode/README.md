# add-budget-renewal-mode

"Budget Review" for an operating project (the PM team's name for it): read last year's approved budget by line code
into the Existing-project form, run the pipeline, and set the approved figure beside the tool's new-year figure on a
`Review` sheet of the analysis workbook, with how each figure was obtained. MVP proposed 2026-10-20 for the PM
presentation of 2026-10-21; the carry-forward rules for lines other than staff and utilities are the next change.
